# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, welcome beginners, and keep discussions
about code, not people. Harassment of any kind is not tolerated.

Report problems to the maintainer via GitHub (@MBotirjonDev) or Telegram (@MBotirjon03).
